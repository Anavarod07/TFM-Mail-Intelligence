# TFM: Sistema Inteligente para la Clasificación y Gestión de Consultas Comerciales

## Descripción

Este proyecto corresponde al Trabajo Fin de Máster del Máster en Data Science, Big Data & Business Analytics.

El objetivo del proyecto es desarrollar un sistema inteligente capaz de analizar correos electrónicos recibidos por una empresa y detectar automáticamente aquellos mensajes que pueden representar una oportunidad comercial o lead.

El sistema utilizará técnicas de procesamiento del lenguaje natural (NLP) y Machine Learning para analizar el contenido de los mensajes, clasificarlos y extraer información relevante para facilitar su gestión comercial.

El proyecto parte de un problema real identificado en un entorno empresarial, donde la recepción, clasificación y asignación de consultas comerciales requiere actualmente una importante intervención manual.

Debido a las limitaciones para utilizar datos corporativos históricos, el desarrollo y evaluación del sistema se realizará utilizando un dataset público de correos electrónicos.

## Objetivos

- Analizar y preparar un dataset de correos electrónicos.
- Identificar y clasificar diferentes tipos de mensajes.
- Detectar potenciales consultas comerciales o leads.
- Aplicar técnicas de NLP para el procesamiento de texto.
- Entrenar y comparar modelos de Machine Learning para clasificación.
- Extraer información relevante de los mensajes.
- Desarrollar un prototipo que permita demostrar la aplicación práctica del sistema.

## Estructura del proyecto

- `data/raw/`: datos originales.
- `data/processed/`: datos procesados.
- `notebooks/`: análisis exploratorio, experimentación y modelado.
- `src/`: código fuente reutilizable.
- `models/`: modelos entrenados.
- `app/`: aplicación/prototipo.
- `reports/`: gráficos y resultados generados durante el análisis.
